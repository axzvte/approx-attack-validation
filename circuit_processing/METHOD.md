# 当前方法与适用范围

新配置统一采用以下流程，详细命令见 [README](README.md)。

1. 读取已经确定的统计矩形及输入基准配置。此时不读取验证图片的内容。
2. 从有明确输入输出接口的 C 算术内核提取标量运算图，展开固定循环和辅助函数，保存每个运算的连接、类型、源码位置与共享加法器组。现有四个应用均使用这一编码过程。
3. 在图上计算保守的数值范围和近似误差传播，反向计算输出传递系数。系数仅用于候选排序，不构成实际扰动大小的保证。
4. 按统一结构评分检查有数量上限的节点与位候选，再按误差贡献排序逐步精确替换加法器组。默认上限为 128 个候选、512 次前向分析，补偿前缀最多分 64 步，不枚举所有替换子集。
5. 对区域内外输出绝对误差上界 BR、BB 检查 `a*BR²+(1-a)*BB² <= 65.025`，其中 a 为矩形面积占比。这给出相对于全精确参考的全图 PSNR 至少 30 dB 的条件。冻结配置同时保存运算图、选择轨迹和源码指纹。
6. 读取图片，映射固定矩形并复核面积预算，执行已经冻结的配置。分块内核仅在整个输出块位于矩形内时翻转。逐图检查实际误差和区域下降，输出 CSV、Excel 和三图对比。

选择方法是有预算的启发式方法，不保证全局最优；未找到内部证书不代表不存在可行解。像素端备选会单独标记。内部翻转的区域 MSE 下界为 0，实际局部效果仍需图片验证。默认基准是既有混合单元配置，用户可以修改基准后重新冻结。

编码器支持的 C 子集和数值约定见 [kernels/README](kernels/README.md)。它不直接接受任意 C/C++ 工程；当前四个原 C++ 算术实现通过相应 C 内核接入。DCT 逆变换采用双精度矩阵实现，和 OpenCV 优化实现可能在舍入临界值处存在差异。

历史 schema 1/2 冻结文件通过 `legacy_planning.py` 和 `legacy_circuit_profiles.py` 复现原配置。历史的组合枚举和 DCT 特定位置规则不参与新配置的选择。

软件算术和结构分析已有配套 RTL 生成及功能仿真，范围见 [hardware/README](hardware/README.md)；DC 面积综合留待后续。验证图片与区域统计图片重叠时，应在论文中说明属于同批数据验证。
