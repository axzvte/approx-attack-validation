# 多节点位反转联合搜索

本版本将 Sharpening 四个加法节点放入同一个搜索，允许任意子集参与。主结果按 2、3、4 个**实际触发节点**分别报告，不预先指定一个破坏节点、一个补偿节点。目标为全局 PSNR 达到正常下限（默认30 dB），在此条件下尽量降低 ROI PSNR；ROI 可见破坏和背景视觉正常需要看图确认。

没有背景 MSE/PSNR 的额外硬阈值，不要求全局指标恢复到基准，也没有 deltaROI>deltaNonROI 的硬门槛。阈值16的覆盖率、背景均方误差与空间统计都只是辅助诊断，不是视觉成功判据。

新增代码和测试由用户在终端执行。编写方完成静态自查，未编译、运行测试或实验；独立审查服务因额度限制未完成。历史版本测试通过不代表本版本已经通过。

## 更新及运行

在已有仓库根目录的 Linux/WSL 终端中，需要 C++17、CMake、OpenCV 开发库、Python 3：

```bash
git fetch origin
git switch feature/sharpen-bitflip
git pull --ff-only origin feature/sharpen-bitflip

# 首轮运行第1张图片，默认 beam=4、refinement=1、budget=24、top=2、restarts=2
bash scripts/run_sharpen_bitflip_joint.sh data results/bitflip/joint_trial_01 1
```

输出目录必须不存在。脚本编译新工具、记录代码版本与日志，再在本机运行。联合搜索比独立单节点分析更耗时，进度输出给出 restart/pass/目标节点/状态数，不提供未经测量的时间估计。

可显式调整参数，例如增加保留状态和调整轮数：

```bash
bash scripts/run_sharpen_bitflip_joint.sh data results/bitflip/joint_trial_01_wider 1 8 2 32 3 2 30
```

位置参数依次为：图片、每个配置节点数桶的 beam 宽度、初始遍历后的 refinement 轮数、区间边界预算、每个实际节点数的导出候选数、正序/逆序交替起点数、最终全局 PSNR 下限。0 边界预算枚举全部端点，可能显著增加耗时；它并不让整个多节点启发式搜索变成全局穷举。

## 条件评分为何包含节点相互作用

修改目标节点时，使用当前合法联合状态的真实采样，获得该节点**反转前**的输入与输出。当前目标节点先从配置中移除，其他节点保持开启；逐像素分别重放目标节点不触发和触发后的后续电路。下游的输入、原输出位状态、监测值及触发判断全部重新计算。

同一状态下某个监测值的 ROI/背景最终 SSE 变化被聚合，用前缀和评价闭区间。这里并未相加各节点相对于原基准的独立误差。原加法器内部、位宽、0–255最终截断和共享 ROI 都保持不变。

一个重要情形是：移除目标节点时，其他配置可能使下游输入越界；目标节点恢复触发后又可以消除该越界。评分保留了 off 路径的无效样本数以及 on/off 的有符号无效计数差，允许这种修复。最终区间仍必须让所有输出像素合法，不能只评价有效子集。

## 搜索与限制

- 四节点均可关闭，或采用一个监测信号、一个非符号位和一个区间；位为0–11，输出为13位补码。
- 中间状态只要求电路合法，不因全局质量暂时不达标就删除。
- 各配置节点数分别保留多个状态，覆盖 ROI 损伤、低全局代价和背景误差等不同权衡；背景指标仅用于候选多样性，不作硬约束。
- 使用正序/逆序搜索起点和多轮逐节点调整。改变上游节点时，后续节点的触发也会改变。
- 默认区间候选包含所有单点、连续2/3/4/8/16个观测值的短窗口，以及采样边界形成的区间；单点合法，但不再只精查单点而忽略相邻窄区间。
- 每个最终候选都用原 `SharpenApplication` 完整执行核对评分。无触发节点会被移除，再核对输出逐像素不变；不足2个实际触发节点不会充作主结果。
- 搜索是有预算的启发式方法。找到合法配置说明存在相应数值效果，没找到不证明理论不可能。逐图自由选硬件也不证明跨图片固定硬件或未见数据泛化。

## 输出及判断顺序

| 文件 | 内容 |
|---|---|
| `summary.csv` | 原基准、2/3/4节点候选及数值无解状态，区域指标、变化和覆盖率 |
| `configurations.csv` | 每个候选所有节点的翻转位、监测信号、上下界及实际区域触发次数 |
| `ablations.csv` | 每次关闭一个节点后的全局/区域变化，移除后越界也明确记录 |
| `tiles.csv` | 8×8空间网格内分别统计ROI/背景误差和变化覆盖率 |
| `search_stats.csv` | 条件上下文次数、缓存、区间评价数、越界拒绝数、中间质量失败保留数 |
| `RUN.txt` | 参数、基准、ROI、质量参考与完成状态 |

数值候选标记 `status=numeric_eligible`、`visual_status=pending_user_review`，不自动标记研究成功。`no_numeric_candidate` 保留空的攻击指标，不能用基准伪装成成功。参与节点数以最终执行实际触发为准，并不意味着每个节点的单独边际作用都非零，具体作用由消融结果观察。

每个候选的图像包括：

- `*_output.png`：原尺寸联合输出。
- `*_comparison.png`：从左到右为精确、近似基准、联合输出，原比例。
- `*_roi_comparison.png`：相同ROI包围盒，最近邻放大2倍；不改变用于评价的原图。
- `*_background_comparison.png`：三张图的ROI统一遮成灰色127，便于观察背景。
- `*_diff_baseline_x4.png` / `*_diff_exact_x4.png`：同一4倍增益的绝对差图，超过255统一截断。
- `*_without_A*.png`：逐节点关闭后的合法输出；越界移除状态没有伪造图像。

先检查全局达标，再看ROI是否有明显且非仅少数异常点的损伤、背景是否有明显伪影。可以从多个候选中选择视觉上合适的结果；最小ROI PSNR的一行不自动等于最合适结果。

消融表的差值定义为“关闭节点后 MSE − 联合 MSE”。正值表示关闭后误差增加，即该节点在当前联合配置下提供了补偿；负值表示关闭后误差减少。背景和ROI可能方向不同，且该边际作用不是节点固有属性，也不能与其他消融量简单相加。
